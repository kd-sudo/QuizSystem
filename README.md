# QuizSystem

Настільний застосунок на **Python** із використанням **PyQt6** та локальної бази даних **SQLite** для проведення тестувань, керування тестами й результатами та експорту даних у формат **CSV**.

## Призначення системи

Застосунок призначений для організації комп'ютерного тестування знань із розмежуванням ролей користувачів (студент і викладач), збереженням тестів та результатів проходження у локальній базі даних та можливістю вивантаження результатів у CSV-файли.

## Основні модулі проєкту

- `main.py` — точка входу та ініціалізація застосунку.
- `auth.py` — авторизація та перевірка облікових даних користувачів.
- `database.py` — підключення та операції з локальною базою даних SQLite.
- `paths.py` — формування шляхів до файлів проєкту та бази даних (для запуску з вихідного коду та з готового виконуваного файлу).
- `student_window.py` — вікно та сценарії роботи студента.
- `teacher_window.py` — вікно викладача, керування тестами/результатами та експорт у CSV.
- `test_run_window.py` — вікно проходження тесту.
- `quiz_system.db` — локальний файл бази даних SQLite.

## Вимоги до середовища

- Для запуску готового виконуваного файлу: операційна система Windows, `main.exe` та файл бази даних `quiz_system.db` в одній директорії.
- Для запуску з вихідного коду: встановлений інтерпретатор Python, бібліотека `PyQt6` та файл `quiz_system.db` у корені проєкту.

## Запуск готового виконуваного файлу

1. Переконайтеся, що файл `quiz_system.db` знаходиться в тій самій папці, що й `main.exe`.
2. Запустіть `main.exe` подвійним натисканням або з командного рядка.

## Запуск із вихідного коду

Відкрийте термінал у кореневій папці проєкту та виконайте:

```bash
python main.py
